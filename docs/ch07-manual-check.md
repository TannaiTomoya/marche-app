# 07章の手動確認

## 準備（本人の作業）

1. Stripeのサンドボックスでアカウントとテストキーを用意する（Issue #14）。
2. 手元の `.env` に `STRIPE_SECRET_KEY` と `STRIPE_PUBLISHABLE_KEY` を設定する。値はチャット・PRに貼らない。
3. ブランチ `feature/weekday-2` を取得し、`uv sync`、`uv run flask db upgrade` の後に `uv run flask run` でサーバーを起動する。

## 画面で確かめる

- [ ] 購入者でログインし、2種類の商品をカートに入れて注文する。
- [ ] Stripe Checkoutに商品名・数量・円の合計が正しく出る。スクリーンショットを撮る。
- [ ] テストカード `4242 4242 4242 4242`、未来の有効期限、任意の3桁CVCで支払う。
- [ ] 自分のアプリの「お支払いを確認しています」に戻る。注文は支払い待ちのまま。
- [ ] Stripeダッシュボードのテスト支払い一覧に記録される。スクリーンショットを撮る。
- [ ] 別の注文でCheckoutの「戻る」→中断ページ→「この注文を取り消す」。注文が取り消しになり、予約された在庫が戻る。
- [ ] TablePlus等で `orders.stripe_checkout_session_id` に `cs_test_...` が保存されている。
- [ ] PRに2枚のスクリーンショットを貼り、実際に確認したチェック欄を埋める。

確認が終わり、CIが緑になってからPRをマージする。mainを取得し、Issue #15の提出文を使ってSlackに投稿する。
